# Save items pill: policy questions from the chat adjudication

- **Health, supplements and substances (3 items: NAC at 8:30pm, post-MDMA supplement stack, 2,650 calorie target).** Should anything health related ever be offered? Recommended default: offer only a routine the user sets themselves with a concrete time or amount (the NAC habit, which the user saved), worded neutrally. Never offer anything that records drug use, prescription medication, diagnoses or mental health, and skip one-off regimens.
- **Items raised inside emotional conversations (3 items: Liv leaving in two weeks, leaving Provincetown tomorrow, the principled kindness reflection).** Should the pill appear while someone is processing something hard? Recommended default: no pill during emotional or venting turns. Offer a plain event once the chat turns practical, never one that could read as a nudge (a departure the user says they don't want), and offer a reflection only when the user asks to keep it, in their own words.
- **Recommendations the user asked about but never adopted (4 items: Tunnel Tops, GLTF twice, SF Botanical Garden).** The labelling guide counts "asked more about" as engagement, but the app rule needs the user to take it up. Recommended default: leave unless the user signals adoption ("I'll try it", "great shout, do I need to book"), and change the guide wording to match.
- **Explicit asks to save, remember or change something (4 items: todo to book Dave's birthday, Saturday call with Mum, Mexico context update, shed one box a day).** Recommended default: always offer. Gremly also replied "I've updated my records" and "I've set that up" before anything was saved, so either save automatically on an explicit ask or stop Gremly claiming it has. An edit request should replace the existing item, not add a second one.
- **Hedged or vague intentions (6 items: plan the sister's visit, plan Dave's Berlin birthday, alcohol talk with Dave, office three days, Sunday deep work block, find coworking near a gym).** Phrases like "maybe", "worth a discussion" or "I need to figure out" with no concrete action. Recommended default: leave unless the user firms it up later in the chat ("will do", "yes"), and never add a vague "plan X" todo next to an event for X that is already offered.
- **Same-day plans and things Gremly already knows (6 items: bonfire tonight, Dolores Park this afternoon, Saturday park day, 6:30am call, Dave's birthday resurfaced from data, fly via Mexico City note).** Recommended default: skip plans for later the same day that the chat itself is arranging, pass the user's existing items and calendar to the extractor, and drop anything that restates them or restates an item already offered in the same chat.
